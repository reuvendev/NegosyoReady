# Five-step hackathon simulation

On the homepage, complete: Barangay → Pin location → Address → Business → Review. At Step 5 choose Simulate Allowed, Simulate Conditional, or Simulate Not Allowed. The result is **fictional** and saved to the local Compliance Passport for presentation. It does not call BiZ Checker or use a verified zoning map. It does not automatically redirect; click Continue to Dashboard.

For genuine preliminary zoning results, complete the assessment on https://bizchecker.online/zoning and import the PDF using the expandable section on the homepage.

Run `npm install` and `npm run dev`. Never commit `.env.local`.
